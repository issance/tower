# Releases

All tower releases are available on the [GitHub release page](https://github.com/juanfont/tower/releases). Those
releases are available as binaries for various platforms and architectures, packages for Debian based systems and source
code archives. Container images are available on [Docker Hub](https://github.com/issance/tower/releases) and
[GitHub Container Registry](https://github.com/juanfont/tower/pkgs/container/tower).

An Atom/RSS feed of tower releases is available [here](https://github.com/juanfont/tower/releases.atom).

See the "announcements" channel on our [Discord server](https://discord.gg/c84AZQhmpx) for news about tower.
