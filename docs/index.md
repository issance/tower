# Welcome to tower

Tower is an open source, self-hosted implementation of the Tailscale control server.

This page contains the documentation for the latest version of tower. Please also check our [FAQ](about/faq.md).

Join our [Discord server](https://discord.gg/c84AZQhmpx) for a chat and community support.

## Design goal

Tower aims to implement a self-hosted, open source alternative to the
[Tailscale](https://tailscale.com/) control server. Tower's goal is to
provide self-hosters and hobbyists with an open-source server they can use for
their projects and labs. It implements a narrow scope, a _single_ Tailscale
network (tailnet), suitable for a personal use, or a small open-source
organisation.
